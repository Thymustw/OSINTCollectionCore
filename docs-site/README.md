# 文件網站（docs-site）

這個資料夾是產品文件網站的原始檔，用 MkDocs Material 產生。
網頁內容在 `docs/`，選單結構在 `mkdocs.yml`。

## 怎麼打開

在專案根目錄（`OSINTCollectionCore/`，不是這個資料夾）執行：

```bash
make docs-serve
```

第一次執行會自動在 `docs-site/.venv` 建立 Python 環境並安裝套件，約需一分鐘。
看到 `Serving on http://127.0.0.1:8000/` 之後，用瀏覽器開：

```
http://127.0.0.1:8000
```

- 改 `docs/` 底下的檔案，網頁會自動重新整理。
- 結束：在終端機按 `Ctrl+C`。

### 從別台電腦看（例如在 Windows 主機上開瀏覽器）

`make docs-serve` 只綁在 `127.0.0.1`，也就是**只有跑它的這台機器自己連得到**。
從別台電腦開會連不到，這是刻意的預設（不讓網路上其他人看到）。

要從別台看，擇一：

1. **SSH 轉埠（建議）**：在你自己的電腦上執行
   ```bash
   ssh -L 8000:127.0.0.1:8000 <你的帳號>@<這台機器的位址>
   ```
   連上後，在**你自己的電腦**開 `http://127.0.0.1:8000`。SSH 斷線，網站就關閉，不會對外開放。

2. **暫時對外開放**：在 `docs-site/` 裡執行
   ```bash
   .venv/bin/mkdocs serve -a 0.0.0.0:8000
   ```
   再用 `http://<這台機器的位址>:8000` 開。
   ⚠️ 同網段任何人都看得到，用完記得 `Ctrl+C` 關掉。
