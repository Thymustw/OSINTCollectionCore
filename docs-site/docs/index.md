# OSINT Intelligence Core

**一個把公開情報（OSINT）收進來、整理好、找出關聯的平台核心。**

你把各種來源的資料丟進來——資安公告、威脅情報報告、RSS、網頁、JSON、CSV、
STIX——系統會：

1. **原封不動保存原始資料**，每一筆都能追溯回「它是從哪裡、什麼時候、誰收進來的」
2. **自動整理成文件**，並把重複轉載的內容合併
3. **自動抽出情報指標**：漏洞編號（CVE）、IP、網域、網址、Email、雜湊值……
4. **建立搜尋索引**，支援關鍵字、布林、中文，以及語意搜尋
5. **畫成關聯圖**，並從已知的東西出發，**發現還沒注意到的新關聯**

## 先知道這件事：目前沒有操作畫面

這個版本是**平台核心**，對外的操作方式是：

| 方式 | 用途 |
|---|---|
| **REST API**（`http://127.0.0.1:18080`） | 所有功能都從這裡用：匯入、搜尋、查關聯、發現新關聯 |
| **命令列工具** `osint-cli` | 查詢與檢查系統狀態 |
| **Neo4j Browser**（`http://127.0.0.1:7474`） | 圖資料庫內建的網頁介面，可以用視覺化方式看實體之間的關聯 |

規劃中的網頁操作介面（Console）還沒有開發。如果你打開瀏覽器預期看到一個像
OpenCTI 那樣的操作畫面，目前沒有——請改用上面三種方式。

## 版本狀態

| 版本 | 內容 | 狀態 |
|---|---|---|
| V0.1 | 資料層：收集、保存、整理、去重、抽取指標、搜尋 | 完成 |
| V0.2 | 情報關聯：關聯圖、實體合併、語意搜尋、STIX、時間軸 | 完成（部分規格延後） |
| V0.3 | 發現新關聯：從已知實體出發找出相關的新目標、AI 輔助判斷 | 完成（部分規格延後） |
| V0.4 | 自動化：政策引擎、事件偵測、警示 | 尚未開始 |

每個版本「延後了什麼、為什麼」都記錄在 [目前的限制](architecture/limitations.md)。
