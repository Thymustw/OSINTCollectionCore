# 架構

這一章說明 OSINT Intelligence Core 的內部設計：各服務的職責、資料怎麼在系統裡流動、選用哪些技術以及為什麼、還有目前已知的限制。

讀者是想了解系統怎麼設計的開發者，或正在評估這套平台的技術人員。
如果你只想知道怎麼用，從[快速上手](../getting-started/quickstart.md)開始會比較直接。
